# Markdown vs HTML 

So a markdown is plain text with converstions like # means heading but for HTMl, it uses tags. For example, `<h1>...<h1>` is a tag for a big heading.

Your browser can't show a raw .md file because markdown files are for writing and it isn't the web's language so it can't be converted but an HTML is using the web's language so it can be converted.
