# Week 1 day 1

## What I did
I learned short cuts like:

- pwd # "print working directory" - where am I? 
- ls # list files in this directory
- ls -la # list everything, including hidden files, with details
- cd ~ # go to home directory (~ means home)_
- cd .. # go up one level
- cd - # go back to where I just was

I also learned how to create directorys, files, and subfiles in the directory on Ghostty:

- mkdir (name) # creates the directory
- cd (file name) # opens the directory
- touch (file name) # creates a file in the directory
- mv (file name) (new file name) # replaces the file name
- rm -r (file name) # erases the directory

I learned how to print from Sublime Text onto Ghostty

# Example in Ghostty:

- cd ~ dev/brand-lens/
- touch hello.py
- open -a "Sublime Text" hello.py 

Which opens the file in Sublime

# Now in Sublime

- print("hello, world")

Save (cmd-S) and go back to Ghostty and run:

- python hello.py
	
To run the Sublime command on Ghostty which should print "hello, world"
